# Malformed fixtures

Generated by `scripts/make-fixtures.ts`. Do not edit by hand.

Each file is an exact byte sequence the importer has to survive. They are
marked binary in `.gitattributes` so a checkout cannot silently repair them.

unterminated-quote.csv
  A quoted field that never closes. Everything after it would otherwise be read as one enormous value, silently destroying the rest of the register.

bom-and-crlf.csv
  What Excel on Windows actually writes. The BOM must not become part of the first column name.

lone-cr-in-field.csv
  A bare carriage return inside a quoted field, produced by a paste from a Mac-era tool.

ragged-rows.csv
  Rows that are short and rows that are long. Both are padded or truncated and reported, rather than rejecting a register that is three columns ragged on row 900.

formula-injection.csv
  Every character that makes a spreadsheet treat a cell as a formula, in fields that are echoed into the exports.

out-of-range-levels.csv
  Levels outside the configured scale, non-numeric levels, and blanks. Each must be reported as a different kind of problem.

inverted-intervals.csv
  Quantitative bounds the wrong way round, half-open, and negative. None may be silently repaired.

empty.csv
  Zero bytes.

header-only.csv
  A header with nothing beneath it, which is what a filtered export produces.

blank-header.csv
  A first row of empty fields, so there are no column names to map.

not-json.json
  A trailing comma, which is the commonest reason a hand-edited export fails to parse.

json-not-a-list.json
  Valid JSON containing no list of risks.

json-wrapped.json
  The four wrappers GRC exports choose between. All four must be unwrapped.
